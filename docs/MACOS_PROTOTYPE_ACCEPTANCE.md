# macOS 第一阶段原型：人工验收清单

分支：`codex/macos-prototype`。本清单验证真实鼠标、触控板、macOS 窗口及焦点，不将自动测试结果代替人工通过。首版仅支持 Apple Silicon 本机体验。

启动：项目根目录运行 `npm run mac:start`；或打开 `desktop-macos/release/晾一晾-darwin-arm64/晾一晾.app`。请只启动一份。关闭看板不会退出应用；菜单栏「退出晾一晾」才退出。

## 建议先做的六项重点验收

| 勾选 | 操作 | 预期结果 |
| --- | --- | --- |
| [ ] | 把其他应用窗口放到透明挂件后面，点击杆下方没有人物、绳子或便签的空白处 | 能点击/输入底层应用，没有白色/黑色矩形遮住桌面；图片自身的绿色背景属于原照片 |
| [ ] | 在人物上按下并向下、向侧边拉，鼠标移出挂件范围后再松开；再试直接拉绳子 | 绳子可抓，独立动画窗继续显示人物；鼠标松开后能够结束手势，不会永久卡住 |
| [ ] | 拉距超过约 45 点后松手；也试短距离拖动 | 长拉有蓄力/瞄准点、弹飞和音效，人物飞出屏幕后回原位；短拖回弹 |
| [ ] | 新建便签，向挂架外或废纸篓拖动；再试在杆内松开 | 拖出小窗口仍可看到整纸；投出后卷纸并恰好完成一次；杆内松开回弹 |
| [ ] | 菜单栏点「原型测试：10 秒后到期」，切换到其他应用连续打字至少 20 秒 | 到点后角色与气泡追着真实鼠标移动、镜像翻转；键盘一直留在原应用，不抢焦点；点击气泡能穿透 |
| [ ] | 在该任务详情点「开始处理」；另建测试再点「稍后 10 分钟」 | 该任务的追逐立即停止，截止时间不改变；如有其他任务超时，可切换到下一任务而不是叠加多个追逐窗 |

若第一项或第五项失败，请记录失败时底层应用、是否全屏、鼠标/触控板、按下还是移动时发生。它们是后续重点修正项，不应被视为已经验收通过。

## 追逐手感复核（首轮体验调整）

- [ ] 触发超时后慢慢移动鼠标：角色稍落后于鼠标，连续追赶；保留原有镜像翻转，移动时轻微倾身与起伏。
- [ ] 快速横移，再突然反向：角色先加速追赶，反向时有刹车转向的过程，不瞬间贴到鼠标旁。
- [ ] 停住鼠标约 1–2 秒：角色追到旁边后缓停，不持续漂移或抖动；镜像翻转继续保留。
- [ ] 沿屏幕左右边缘来回移动：换侧时连续移动，不在左右两边瞬移；角色和气泡保持在可用屏幕内。
- [ ] 在其他应用边打字边移动鼠标，检查追赶过程持续穿透且不抢焦点；开始处理/稍后仍立即停止当前追逐。

可反馈「跟得过紧/太慢」「转向拖沓」「起伏太多」等手感，后续按实际体验调整。本轮不改变提醒时机、持续追逐和任务轮转规则。

## 菜单栏、窗口与提醒

- [ ] 刚启动时工具栏隐藏；鼠标移到杆、人物或便签后显示，移到工具栏可正常点击和拖动，移出后隐藏；隐藏位置不挡底层应用的点击。
- [ ] 无待办时陪伴搭子居中悬挂；增加便签后，整组挂件按原看板方式居中排列，溢出时仍可横拖。
- [ ] 点击挂件或看板使应用获得焦点，按 `⌘+`（或 `⌘=`）/`⌘-`：杆、人物和便签一起放大/缩小；`⌘0` 恢复；「视图」菜单也可操作。
- [ ] 缩放后分别拉人物、拉绳子、弹飞、重拍及投便签，检查没有跨窗跳位、纸张大小突变；退出重开保留缩放。切到其他应用时，这些快捷键仍由其他应用自己处理。
- [ ] 菜单栏图标能打开「显示便签架」「隐藏便签架」「打开看板」「我的搭子」「安静 / 恢复提醒」「退出晾一晾」。
- [ ] 关闭看板，再从挂件「看板」或菜单栏恢复，数据还在。
- [ ] 拖工具栏「晾一晾便签」移动整个挂架；退出重开后位置保留且仍可见。
- [ ] 建立 10 秒测试便签后立刻隐藏挂件，等待到期；仍出现追逐。
- [ ] 安静后所有自动提醒/追逐停止；恢复后继续按真实时间计算。
- [ ] 在设置开启「减少动态效果」，追逐和激烈动作停止，保留文字提示；关闭后按设置恢复。
- [ ] 连续建立 3 张测试便签，等待超时；始终只有一个追逐；默认约每 60 秒轮到其他候选，修改重复间隔后按该值轮转。
- [ ] 追逐中完成当前任务，出现完成台词，并结束该任务追逐；其他未完成任务仍保留。
- [ ] 菜单栏退出后没有残留角色、气泡或透明挡鼠标的窗口。

## 原界面与资源

- [ ] 原看板布局、颜色、素材、便签纸、搭子和台词编辑界面符合原项目预期。
- [ ] 添加/编辑/完成/撤销/取消/历史恢复在看板与挂件之间同步。
- [ ] 中文输入法、⌘C/V/Z、Esc 和模态焦点正常。
- [ ] 添加好友，选择照片卡、棒球衫或小猫，导入 PNG/JPG/WebP；保存后上架，重开仍显示。
- [ ] 点击「自动抠图」能完成，再点「使用原图」能恢复。断网后仍可执行。
- [ ] 自定义模板上传、圈脸、修边、宽高调整与撤销可以操作。此组可在阶段二深入回归；首阶段已保留界面与原实现。
- [ ] 在「陪伴模式 → 解压玩法」同时开启重拍和弹飞，保存后单击人物：聊天、旋转、返回，不影响后续拖动。

## 已知范围与区别

- 当前无正式签名公证、DMG、自动更新、Intel、Mac App Store 或云同步；不要作为正式发行包转发。
- 工具栏悬停显示、便签架快捷键缩放及角色居中已按首轮反馈修正；顶部悬绳等其他外观细节仍待后续与 Windows 基线对齐。
- 缺失的七套历史角色没有补画，旧数据引用这些角色时可能缺图；当前公开的棒球衫、小猫、自定义模板可用。
- 开始处理/稍后立即结束该任务追逐、隐藏仍调度、积压提醒串行轮转是获准的 macOS 行为改进，Windows 代码没有同步修改。
- 自动测试已验证原生窗口和程序内指针路径；底层系统命中、跨应用焦点、多屏与触控板请按本清单实际勾选。

反馈时建议给出：清单项目、操作步骤、预期与实际、鼠标/触控板、显示器数量及系统版本。第一阶段验收通过后再接入/打磨后续完整功能。
